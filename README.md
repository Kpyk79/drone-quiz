# Дрон-Шоу

Live quiz game show for kids: one big screen, a host remote and players' phones.

- Players: `https://kpyk79.github.io/drone-quiz/`
- Host remote: `https://kpyk79.github.io/drone-quiz/?host`
- Big screen: `https://kpyk79.github.io/drone-quiz/?screen=CODE`

Backend: Supabase functions in `sql/schema.sql`, questions in `sql/seed.sql`.
